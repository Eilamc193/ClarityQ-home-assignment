# ClarityQ SDR Home Assignment — ICP Demo Dashboard

An AI-powered outbound intelligence platform built as a take-home assignment for the ClarityQ SDR role. Demonstrates a full pipeline approach: ICP identification → persona research → signal-triggered email generation → pipeline tracking → A/B analytics.

**Live demo:** `npm run dev` → http://localhost:5173

---

## What It Does

| Module | Description |
|---|---|
| **ICP Scanner** | 5 target accounts scored by fit, with enriched company profiles |
| **Signal Feed** | Buy signals dated Q4 2025+ — all pre-October 2025 signals removed |
| **Persona Finder** | Real decision-makers with Hunter.io email lookup (live API) |
| **Email Composer** | 3 email types × 3 tones, generated by Claude Sonnet or served from cache |
| **Pipeline Board** | Kanban drag-and-drop: Identified → Contacted → Replied → Meeting → Closed |
| **A/B Insights** | Win rate by tone, persona title, platform, and email type |

## Tech Stack

- **Frontend:** React 18 + Vite + Tailwind CSS
- **AI:** Anthropic Claude Sonnet 4.6 (`claude-sonnet-4-6`) via browser API
- **Email discovery:** Hunter.io API
- **State:** Zustand + localStorage (pipeline board + A/B data persist across sessions)
- **Email cache:** Pre-generated emails for all current personas (Claude API fallback for edge cases)

## Quick Start

```bash
cd dashboard
cp .env.example .env     # add your API keys
npm install
npm run dev
```

### Environment Variables

```
VITE_HUNTER_API_KEY=your_hunter_api_key
VITE_ANTHROPIC_API_KEY=your_anthropic_api_key   # optional — cache covers all real personas
```

### Build

```bash
npm run build   # outputs to dashboard/dist/
```

## Signal Feed Policy

All buy signals are dated **Q4 2025 (October 2025) or later**. The signal feed reflects current intelligence — no outdated signals from 2024 or earlier appear in the UI. Each signal includes a "Why this matters for ClarityQ" relevance note tied to ClarityQ's core value prop.

## A/B Insights

Pre-seeded with 23 mock response events. New responses are logged automatically when pipeline cards advance to **Replied**, **Meeting Booked**, or **Rejected** stages. Insights surface in real time: win rate by tone, persona seniority, platform, and email type.

## Profile Photos
